These are existing screenshots from the library's DHT example, copied into this
wiki so image links do not depend on a working device or an external image host.
They illustrate the portal layout. Older captions can differ from current name
validation, heap diagnostics, gzip support and the optional Messages tab. The
reference pages describe current behavior.
